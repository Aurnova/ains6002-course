# How to Use AINS6002

This page is the starting point for **AINS6002 [Machine Learning](glossary.md#machine-learning) & Predictive Modeling**. The course is not a collection of unrelated files: each module follows the same learning sequence.

## Student Path: One Module at a Time

1. **Orient:** open the module overview and read its essential question, scenario, outcomes, and required artifact.
2. **Learn:** read the book-prose chapter. Use the study questions to check comprehension.
3. **See the explanation:** open the slide deck. The matching narration provides the spoken teaching script when the course is asynchronous.
4. **Practice:** launch the lab in [Google Colab](glossary.md#colab), run all [cells](glossary.md#cell), change one named [variable](glossary.md#variable), and record what changed.
5. **Demonstrate:** complete the assignment [notebook](glossary.md#notebook) and compare your work with the rubric before submitting.

Do not begin by opening every [file](glossary.md#file) in the [repository](glossary.md#repository). Start with the overview for the current module and follow the links in order.

## What the Course Terms Mean

- **Jupyter Book:** the web textbook you are reading. It combines prose, notebooks, assignments, and teaching materials into one navigable site.
- **Course repository / [GitHub](glossary.md#github) hub:** the public cohort repository at [https://github.com/Aurnova/ains6002-course](https://github.com/Aurnova/ains6002-course) contains the student-facing source files for cloning and notebook work.
- **Notebook:** an interactive document containing explanations, executable code, [output](glossary.md#output), and response areas.
- **RISE-ready slides:** slide notebooks include presentation metadata. Anyone can read the rendered slide page in a browser; facilitators can open the notebook in JupyterLab and use RISE for full-screen presenter mode.
- **Colab:** Google's browser notebook environment. The provided labs work with the free tier; a paid Colab Pro subscription is not required.
- **[Codespaces](glossary.md#codespaces):** a browser-based copy of the complete repository for activities that need several files, a [terminal](glossary.md#terminal), or [Git](glossary.md#git).

## If You Get Stuck

First check [Technical Requirements and Setup](technical-requirements.md). Then record the module number, the link you opened, the step that failed, and any visible error message for your instructor or course support channel.
